# Kushal Govind Gupta — Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded from the internet; system fallbacks are included.

## Customize
- Update contact details and profile content in `index.html`.
- Update colors, spacing and responsive styles in `style.css`.
- Update mobile navigation behavior in `script.js`.

## Deployment
Upload the three files (`index.html`, `style.css`, `script.js`) to GitHub Pages, Netlify, or Vercel as a static site.

## Resume source
Content is based on the supplied resume. No profile photo or resume download file was supplied, so the hero uses a typographic monogram.
